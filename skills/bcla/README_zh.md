# BCLA 主技能

触发条件：用户显式调用 `@BCLA`、`@bcla` 或 `$bcla:bcla`。

目的：在当前会话中组织 LoongArch64 镜像构建，并共享会话历史。

功能：建立目标、选择专项技能、保存关键决策、暂停及验证恢复条件、检查最终镜像和测试证据。执行循环交给 Codex，任务存储不下发工作项。普通讨论可以读取日志但不自动恢复构建。

详细规则见 [SKILL.md](SKILL.md)。

构建镜像不等于从源码编译主程序。识别到尚无可用产物时，先读取 fix-pkg-miss 及来源参考，实际检索并验证，再决定复用、CI 或源码路线。知识库未命中、官方只有 amd64 包，都不能直接作为自行编译的理由；获取结论可以保存在普通检查点。

任务记录通过检查点、决策和资源清单保存进度、路线依据、事实和恢复位置。工具保存命令及任务版本，并提示尚未整理的执行结果。模型在进度变化、路线切换和暂停前更新记录。
