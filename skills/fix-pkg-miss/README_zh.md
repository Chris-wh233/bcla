# 缺失资源处理

触发条件：已识别的必需非镜像产物尚未验证并可用，包括项目自身二进制、发行包、库、工具及生成文件；在选择源码构建之前触发，不必先构建失败。

目的：优先复用现有资源，避免不必要的源码构建和辅助生成链移植。

功能：按指定顺序检索 LoongArch 来源，上游 Release 最后；验证真实消费者兼容性；必要时从源码构建。若架构无关产物更适合在 x86 生成，则直接记录等待并暂停，不要求先解决其原生生成器依赖。支持用户提供产物恢复，以及 manual/local-build 两种 CI 行为。

详细规则见 [SKILL.md](SKILL.md)，来源见 [sources.md](references/sources.md)。

记录实际查询来源、结果、候选验证或拒绝原因及最终获取路线。已验证资源可直接复用，不必查完低优先级来源；进入源码兜底前则需交代适用来源和 CI。只有文件名含 loong64 不能证明兼容 Alpine，需要检查实际 ABI 和消费结果。

搜索和验证结果记录在资源清单中，并注明产物的消费者。新增依赖时检查该组件的来源和 CI，再评估当前路线；获得产物后回到消费者验证。
