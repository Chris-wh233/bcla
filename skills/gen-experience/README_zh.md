# 生成构建经验

触发条件：任务为 SUCCEEDED，且用户显式调用 `$bcla:gen-experience`。

目的：将本次最终成功方案整理为可复用的知识库配方。

功能：读取实际命令和测试证据、保存的 Dockerfile/补丁，生成 experience.json、构建说明及平级依赖经验；验证文件和索引，在知识库 main 的结构化目录中本地提交。不会自动推送，缺少事实时不会从聊天猜测补写。

详细规则见 [SKILL.md](SKILL.md)。

从最终结果、资源清单、接受文件和执行证据生成经验。排除废弃路线，保留实际参与成功构建的临时修改及复现步骤。

新经验使用 schema 3，按 `<组织>/<仓库>/<版本>/<运行基础镜像家族>/` 保存，例如 `mysql/mysql-server/8.4.0/debian/` 与 `8.4.0/alpine/`。家族不含标签和仓库前缀，但元数据记录实际生效的基础镜像、已知 digest、libc 等信息。根据最终运行环境、构建参数覆盖与阶段继承判断，不以辅助容器或 builder 阶段命名。

同一任务有多个家族时分别生成经验，每份只包含对应目标和必要证据，依赖经验平级放在各自 `dependencies/` 中。不同家族可并存；同一家族仍执行既有冲突处理，不用标签后缀规避冲突。项目索引统一列出版本和家族，不在版本目录生成索引。知识库 README 仍保留，不受 gen-maker 精简交付目录规则影响。

已有经验库不自动迁移。详细结构和候选选择约定见 [知识库结构](../../docs/knowledge-layout.md)。
